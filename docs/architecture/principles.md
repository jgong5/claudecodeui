# Project principles

These add to the agent-team default principles; where they conflict, these win.

## Server and client code follow their module standards

Code under `server/` follows `.agents/skills/backend-module-standards/SKILL.md`, and code
under `src/` follows `.agents/skills/frontend-module-standards/SKILL.md`. Each side keeps
one layout, so a reader who knows one module can read the next.
Source: [`AGENTS.md`](../../AGENTS.md).
